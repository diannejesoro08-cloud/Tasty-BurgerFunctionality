# Tasty Burger

Tasty Burger is a Vite + React + TypeScript burger ordering interface adapted from the original project. The existing visual design, animations, icons, and burger imagery are preserved while the app is updated for the Philippine setting.

## Location

The map and contact location are set to **Sorsogon City, Sorsogon, Philippines**.

## Features

- Vite + React + TypeScript
- Existing Framer Motion animations retained
- Existing Tailwind UI and SVG icons retained
- Philippine peso (₱) prices
- Clickable heart favorites saved in local storage
- Shopping cart with quantity controls
- Sorsogon City Google Maps embed

## Run

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```
